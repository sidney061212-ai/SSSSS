# 《折光回廊》Prototype 0.1 实现规划

## 1. 文档目标
本文用于把后续真正写代码时的工作拆成可执行、可审核的小任务。当前文档阶段不写代码，只定义任务顺序和验收标准。

## 2. Prototype 0.1 目标
实现第 1 关“错位的光”。

本阶段目标聚焦：
- 第 1 关可运行
- 单镜拖动与旋转可用
- 光线反射与光能衰减正确
- 可通关、可重置、可简单结算

## 3. 实施原则
- 每个任务单独 commit。
- 不要一次性完成所有任务。
- 每次完成后等待审核。
- 始终围绕第 1 关垂直切片，不提前加入后续机制。

## 4. 任务拆分
### Task 1：创建微信小游戏工程骨架
目标：
- 创建最小可运行的微信小游戏工程。
- 能在微信开发者工具中打开并进入竖屏画布。

验收：
- 微信开发者工具可打开
- Canvas 显示背景
- 主循环正常运行

本任务只做：
- 最小入口文件
- 画布初始化
- 基础主循环

本任务不做：
- 关卡数据
- 光路模拟
- 镜子交互

### Task 2：建立基础类型和关卡数据
目标：
- 搭建核心类型定义。
- 建立第 1 关 LevelConfig。

验收：
- 有第 1 关数据
- 有光源、出口、镜子、评分目标

本任务只做：
- 基础类型
- LevelConfig 结构
- 第 1 关“错位的光”数据

本任务不做：
- 障碍
- 聚光点
- 多关卡切换

### Task 3：绘制基础场景
目标：
- 让第 1 关的静态画面可见。

验收：
- 背景
- 光源
- 出口
- 镜子
- HUD

本任务只做：
- 背景渐变
- 光源、出口、镜子的基础绘制
- 顶部 HUD 基础文本

本任务不做：
- 光线路径
- 动效打磨
- 通关卡片

### Task 4：实现镜子拖动
目标：
- 玩家可以选中并拖动镜子。

验收：
- 可选中镜子
- 可拖动
- 不拖出关卡区

本任务只做：
- 触摸命中镜子
- 拖动状态
- 位置限制

本任务不做：
- 旋转
- 复杂拖动吸附
- 镜子碰撞约束

### Task 5：实现镜子旋转
目标：
- 玩家可以通过点击镜子进行固定角度旋转。

验收：
- 点击镜子按固定角度旋转
- 旋转后光路重新计算

本任务只做：
- 点击与拖动区分
- `45°` 步进旋转
- `lightDirty` 标记刷新

本任务不做：
- 自由旋转手柄
- 多指操作

### Task 6：实现光线模拟
目标：
- 从光源出发得到可视光路结果。

验收：
- 光线从光源出发
- 命中镜子后反射
- 命中出口判定通关
- 能量耗尽提示光能不足

本任务只做：
- 单光源
- 单出口
- 单镜反射
- 线性光能衰减
- 越界 / 未命中 / 光能不足提示

本任务不做：
- 多光源
- 分光
- 聚光点
- 颜色出口

### Task 7：实现结算和重置
目标：
- 玩家通关后得到轻量反馈，也能快速重新尝试。

验收：
- 通关显示“光已抵达”
- 显示用镜数量和剩余光能
- 可重新挑战
- 可重置

本任务只做：
- ClearResult 简易卡片
- 重置当前关卡
- 从原始数据恢复镜子初始状态

本任务不做：
- 正式三星动画
- 下一关切换
- 本地记录

### Task 8：体验打磨
目标：
- 把 Prototype 0.1 打磨到可以稳定演示。

验收：
- 光线清晰
- 拖动手感可用
- 竖屏适配正常
- 无明显卡顿

本任务只做：
- 光线视觉清晰度调整
- 镜子选中反馈
- 文字和按钮位置微调
- 真机或开发者工具的基础性能观察

本任务不做：
- 全量 UI 重做
- 复杂粒子特效
- 首页包装

## 5. 推荐提交节奏
建议提交顺序：
1. `Task 1` 单独提交
2. `Task 2` 单独提交
3. `Task 3` 单独提交
4. `Task 4` 单独提交
5. `Task 5` 单独提交
6. `Task 6` 单独提交
7. `Task 7` 单独提交
8. `Task 8` 单独提交

原因：
- 便于逐步审核和回退。
- 便于定位问题来源。
- 防止 Codex 一次性写太多代码失控。

## 6. 每个任务后的检查点
每次任务完成后都应检查：
- 是否仍然是微信小游戏竖屏方向
- 是否没有提前实现分光聚能点
- 是否没有引入多关卡或商业化模块
- 是否仍然能围绕第 1 关自洽运行

## 7. 本阶段做什么
- 把 Prototype 0.1 的代码阶段任务拆成 8 个连续小任务。
- 为每个任务给出明确验收标准和边界。

## 8. 本阶段不做什么
- 不创建工程骨架。
- 不写任何实现代码。
- 不开始 Task 1。
- 不合并多个任务为一次性大提交。
