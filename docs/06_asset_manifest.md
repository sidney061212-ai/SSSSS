# 《折光回廊》资产清单

## 1. 资产策略
MVP 阶段遵循“少而准”的原则。优先保证解谜信息可读，再补氛围资产。所有资产都按 P0、P1、P2 分级：
- P0：没有就无法游玩
- P1：没有不影响通关，但体验明显打折
- P2：纯润色与包装

## 8. 占位优先顺序
1. 先做所有 P0 解谜装置的占位图和状态区分。
2. 再补 P0 光效，确保调试解谜时能直接读懂结果。
3. 然后补 P1 的 UI 和环境氛围。
4. 最后再考虑 P2 细节装饰。
