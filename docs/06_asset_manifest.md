# 《折光回廊》资产清单

## 1. 资产原则
当前版本优先使用可快速迭代的轻量资产方案。凡是直接影响玩法读图和交互反馈的元素，优先代码绘制；凡是承担包装、传播和视觉情绪的元素，优先 AI imaging 生成。

## 2. 代码绘制

### 2.1 玻璃卡片
- 用途：首页按钮底板、结果页面板、设置页容器
- 形式：半透明圆角矩形，带高光描边和轻模糊
- 优先级：P0

### 2.2 光线轨迹
- 用途：Gameplay 主视觉与玩法核心反馈
- 形式：带柔和外发光的折线或曲线段
- 优先级：P0

### 2.3 棱镜基础形状
- 用途：关卡中的可点击装置
- 形式：简洁几何体，支持旋转态、切换态、移动态
- 优先级：P0

### 2.4 关卡节点
- 用途：LevelMap 关卡星图
- 形式：发光圆点或钻石节点，支持已解锁、未解锁、已完成三态
- 优先级：P0

### 2.5 进度条
- 用途：Gameplay 和 FailResult 中展示推进程度
- 形式：细长发光线条，末端圆润
- 优先级：P0

### 2.6 按钮
- 用途：首页、结果页、设置页、星图
- 形式：玻璃拟态按钮，带轻高亮和按下反馈
- 优先级：P0

### 2.7 粒子
- 用途：点击反馈、通关反馈、背景轻氛围
- 形式：小颗粒漂浮点、短促扩散点
- 优先级：P1

### 2.8 发光边框
- 用途：按钮聚焦、结果页强调、棱镜可点击态提示
- 形式：细描边加外发光
- 优先级：P1

## 3. AI imaging 生成

### 3.1 首页主视觉光球
- 用途：Home 首页核心视觉锚点
- 要求：清亮、柔和、层次丰富，不做赛博朋克
- 优先级：P1

### 3.2 小程序封面
- 用途：小游戏入口封面和项目展示
- 要求：远看可识别，标题区留出空间
- 优先级：P1

### 3.3 分享卡片背景
- 用途：分享海报底图
- 要求：保持蓝紫玻璃拟态气质，不抢文案
- 优先级：P1

### 3.4 皮肤图标
- 用途：MVP 1.0 基础皮肤展示
- 要求：风格统一、轮廓清楚、适合小尺寸显示
- 优先级：P2

### 3.5 成就徽章
- 用途：本地记录和阶段完成展示
- 要求：轻量、细线、发光边缘
- 优先级：P2

### 3.6 背景氛围图
- 用途：Home、LevelMap、结果页背景
- 要求：大面积留白、轻粒子、低干扰
- 优先级：P1

## 4. 文本与音频

### 4.1 文本
- 首页标题与按钮文案
- 8 关简短提示文案
- 失败页固定文案
- 通关页文案
- 分享文案

### 4.2 基础音频
- 点击棱镜音
- 光线命中终点音
- 光线被吸收音
- 失败页轻熄灭音
- 通关页轻提气音

## 5. 资产优先顺序
1. 先完成代码绘制的玩法核心元素，保证 Prototype 0.1 可玩。
2. 再补结果页和星图所需的基础 UI。
3. 然后补首页主视觉、分享卡片背景等 AI imaging 资产。
4. 最后再做皮肤图标和成就徽章。

## 6. 资源控制要求
- 首阶段不要引入大体积逐帧动画。
- 所有包装资产都不能牺牲加载速度。
- 如果 AI imaging 资产与代码绘制元素风格冲突，优先以代码绘制的玩法读图标准为准。
