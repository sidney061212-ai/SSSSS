# 《折光回廊》项目简述

## 1. 项目一句话
《折光回廊》是一款微信小游戏竖屏短局挑战产品。玩家只通过点击屏幕旋转或切换棱镜方向，让光线在几十秒内抵达终点，追求“差一点就过”的不服感与连续重开欲望。

## 2. 产品定位
- 平台：微信小游戏
- 使用场景：通勤、排队、等餐、碎片时间
- 屏幕方向：手机竖屏
- 核心操作：单指点击
- 单局时长：30 到 90 秒
- 失败后重开耗时：1 秒内
- 目标用户：喜欢轻操作、高反馈、愿意反复冲刺更好结果的休闲玩家

## 3. 核心体验目标
1. 玩家进入关卡后，3 秒内能看懂起点、棱镜、终点和当前光线路径。
2. 玩家只用点击就能完成全部解题动作，不需要拖拽手势组合，也不需要虚拟摇杆。
3. 每次失败都要让玩家感觉“已经很接近成功”，愿意立即再来一局。
4. 成功反馈要足够轻盈、透亮、顺滑，让短局通关具备连胜驱动力。

## 4. 核心卖点
- 一指点击即可上手，适合微信小游戏的超低门槛传播。
- 光线折射路径是可见结果，失败原因直观，不需要长教程。
- 关卡长度短，但尾段会制造“只差一次折射”的强烈不服感。
- 视觉走清亮玻璃拟态路线，适合女性向和泛休闲人群，不做压迫感场景。

## 5. 体验支柱

### 支柱 A：一眼能懂
- 每关只突出一个新的判断点。
- 光线变化必须在点击后即时反馈。
- 棱镜状态数有限，玩家靠看就能理解当前解法空间。

### 支柱 B：快速重试
- 失败后不弹冗长结算，不播长动画。
- 主按钮直接回到当前关卡。
- 失败信息强调“差一点”，不传递负面惩罚感。

### 支柱 C：清亮审美
- 画面整体以蓝紫渐变、半透明卡片、柔和发光为主。
- 大量留白，让光线与棱镜成为视觉中心。
- 动效细腻但节制，不做赛博朋克噪声和重工业脏感。

## 6. 当前版本目标
当前文档阶段的目标不是扩展世界观，而是把微信小游戏的核心玩法闭环写清楚，保证后续实现只围绕以下问题推进：
- 点击旋转是否顺手
- 光线路径是否足够清晰
- 失败页是否能刺激再次点击
- 关卡节奏是否适合 30 到 90 秒短局

## 7. 明确不做
- 非竖屏点击式交互方案
- 长流程文本驱动体验
- 人物位移型玩法
- 需要长时间阅读的内容模块
- 首版就做复杂社交系统
- 首版就做数值养成和抽卡

## 8. 成功标准
- Prototype 0.1 能验证点击旋转棱镜的即时乐趣。
- Prototype 0.2 能验证玩家是否愿意因“差一点”主动重试。
- MVP 0.3 能形成 8 关连续通关体验，并保存本地最高进度。
- MVP 1.0 能具备基本分享传播面：每日挑战入口、分享文案、基础皮肤展示。
