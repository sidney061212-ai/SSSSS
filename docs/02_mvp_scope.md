# 《折光回廊》MVP 范围定义

## 1. 范围目标
本项目不是一次性做完整内容，而是分四个阶段逐步验证微信小游戏成立条件。每一阶段都只解决当前最关键的问题，避免过早堆功能。

## 2. 四阶段版本规划

### Prototype 0.1
目标：只验证核心点击闭环。

包含内容：
- 1 关
- 光线移动
- 点击旋转棱镜
- 成功结算
- 失败结算
- 1 秒内重试

不包含：
- 多关卡
- 进度保存
- 分享
- 皮肤
- 设置页复杂项

验收标准：
- 玩家第一次上手 10 秒内知道怎么点
- 失败后愿意连续点击重来至少 3 次

### Prototype 0.2
目标：验证新手机制和初步教学是否成立。

包含内容：
- 3 关
- 教学提示
- 移动棱镜
- 终点前失败场景
- 基础关卡切换

验收标准：
- 玩家能说清楚“移动棱镜”和“旋转棱镜”的区别
- 第 3 关能明显制造“差一点就过”的重试冲动

### MVP 0.3
目标：形成首个可连续游玩的最小产品。

包含内容：
- 8 关
- 本地最高进度
- FailResult 失败页
- ClearResult 通关页
- 基础音效

验收标准：
- 玩家能从第 1 关连续玩到第 8 关
- 本地进度关闭后重新进入仍然有效
- 失败页的“再折一次”点击率显著高于返回首页

### MVP 1.0
目标：补齐基本的小游戏传播组件。

包含内容：
- 12 关
- 每日挑战入口
- 本地记录
- 分享文案
- 基础皮肤展示

验收标准：
- 玩家能区分普通关卡与每日挑战入口
- 分享文案不会破坏整体审美
- 皮肤展示只做轻包装，不影响核心读图

## 3. 当前文档阶段优先级
当前先写清楚 Prototype 0.1 到 MVP 0.3 所需的玩法规则和 8 关草案。MVP 1.0 只定义入口和展示形态，不展开到完整活动系统。

## 4. 必做项
- 竖屏微信小游戏定位
- 单指点击操作
- 30 到 90 秒单局
- 失败后 1 秒内重试
- 8 关草案
- 关卡星图入口
- 本地最高进度
- 基础音效

## 5. 明确排除项
- 人物位移玩法
- 摇杆或多按钮输入
- 长剧情文本
- 大地图式自由游逛
- 复杂任务系统
- 在线排行
- 云存档
- 首版社交裂变玩法
- 复杂皮肤养成

## 6. 体验底线
1. 点击一次就必须看到光路变化。
2. 失败后重新开始不能超过 1 秒。
3. 任何关卡都不能靠说明书式长文字教学。
4. 视觉上必须保持清亮、留白、半透明，不走厚重风格。

## 7. 版本风险边界
- 如果 Prototype 0.1 无法证明点击旋转本身有乐趣，不进入 0.2。
- 如果 Prototype 0.2 无法制造末段不服感，不直接堆到 8 关。
- 如果 MVP 0.3 的 8 关没有形成连续游玩动力，MVP 1.0 不应优先做每日挑战。

## 8. 里程碑对应关系
- Milestone A：完成 Prototype 0.1
- Milestone B：完成 Prototype 0.2
- Milestone C：完成 MVP 0.3
- Milestone D：完成 MVP 1.0 包装补齐
