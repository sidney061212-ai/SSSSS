# 《折光回廊》界面与流程图

## 1. 整体流程概览
```text
启动游戏
  -> 标题页
  -> 新游戏 / 继续游戏
  -> 序章黑屏文字
  -> 房间流程（12 个房间线性推进）
  -> 终端记录插入
  -> 最终房间
  -> 结尾选择
  -> 通关结算
  -> 返回标题页
```

## 2. 标题页
包含内容：
- 游戏标题《折光回廊》
- 四个主按钮：开始、继续、设置、退出
- 右下角版本号与构建日期

交互规则：
- 首次启动时隐藏“继续”或置灰。
- 进入设置后返回标题页，不额外弹窗。

## 3. 新游戏流程
1. 点击“开始”
2. 播放 2 到 3 屏黑底白字序章
3. 进入 R01 入射大厅
4. 自动记录当前存档位置

序章文本目标：
- 交代玩家身份
- 说明进入设施的原因
- 暗示“主存档”存在风险

## 4. 继续游戏流程
- 直接载入最近解锁房间
- 载入后在屏幕上方短暂显示房间名 2 秒
- 不重复播放已看过的序章和日志

## 5. 房间内流程

### 5.1 标准房间结构
1. 玩家进入房间
2. 屏幕上方显示房间名
3. 玩家观察空间布局
4. 进行装置操作
5. 门锁打开或隐藏道路出现
6. 玩家离开房间
7. 自动存档

### 5.2 房间内菜单
- `Esc` 打开暂停菜单
- 选项包含：继续、重置当前房间、设置、返回标题
- “返回标题”必须二次确认，防止误触

## 6. 终端日志插入点
建议在以下节点插入：
- R03 结束后：说明设施用途
- R06 结束后：说明事故前兆
- R09 结束后：说明主研究员的真实决定
- R11 结束后：说明最后选择的伦理含义

日志打开方式：
- 玩家主动靠近终端按 `E`
- 不强制阅读完才能前进，但阅读后会强化结尾动机

## 7. 设置页
必须有：
- 主音量
- 环境音量
- 亮度
- 色盲辅助开关
- 文本字号标准 / 放大

当前阶段不做：
- 分辨率复杂切换
- 键位自定义
- 多语言切换

## 8. 结尾流程
1. 最终房间完成后，主信标恢复
2. 弹出两个选项：“回收存档”“公开播放”
3. MVP 中默认只开放“回收存档”作为可选项，另一项显示为锁定
4. 播放结尾黑屏文字与设施静默镜头
5. 进入结算页

## 9. 结算页
显示内容：
- 通关总时长
- 房间复位次数
- 已阅读日志数量
- 一句评价文案，例如“你选择让光留在回廊内部”

## 10. 流程设计原则
- 任何非解谜界面都要短、快、可跳过。
- 不让玩家频繁回标题页或章节选择页。
- 玩家随时知道自己当前在做什么、下一步去哪。
