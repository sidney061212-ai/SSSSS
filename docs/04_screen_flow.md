# 《折光回廊》界面与流程图

## 1. 固定页面结构
项目页面流程固定为：

```text
Loading / Boot
  -> Home 首页
  -> LevelMap 关卡星图
  -> Gameplay 游戏页
  -> FailResult 失败页
  -> ClearResult 通关页
  -> Settings 设置页
```

## 2. Loading / Boot
目标：
- 完成基础资源加载
- 显示品牌名与光点动效
- 让玩家在短时间内进入首页

规则：
- 不做长时间黑屏等待
- 有加载进度提示，但不做复杂演出
- 完成后自动进入 Home

## 3. Home 首页
页面内容：
- 主视觉光球
- “开始折光”主按钮
- “每日挑战”次级入口
- “设置”入口
- 最近进度提示，例如“已点亮至第 5 关”

交互规则：
- 首次进入点击主按钮直接前往 LevelMap
- 如果已有本地进度，首页要能显示最近解锁关卡
- 每日挑战入口在 MVP 1.0 才启用，早期可以灰显占位

## 4. LevelMap 关卡星图
页面内容：
- 竖向关卡节点
- 当前已解锁关卡高亮
- 星级或完成状态
- 返回首页入口

交互规则：
- 点击已解锁节点进入 Gameplay
- 点击未解锁节点只给轻反馈，不弹硬提示
- 星图滚动要顺手，不能遮挡节点识别

## 5. Gameplay 游戏页
页面内容：
- 顶部：关卡编号、设置按钮、简短进度条
- 中部：棱镜与光线路径
- 底部：极简提示文案

页面内流程：
1. 进入关卡
2. 光线起点短暂亮起
3. 玩家点击棱镜改变方向
4. 实时判断是否抵达终点
5. 成功则进入 ClearResult
6. 未达成且命中错误路径则进入 FailResult

## 6. FailResult 失败页
页面目标：
- 强化“不服”
- 诱导立即重试

页面文案固定使用：
- “差一点就亮了”
- “抵达进度 94%”
- “距离终点只差 1 次折射”
- 主按钮：“再折一次”

辅助元素建议：
- 显示本次失败点高亮缩略图
- 显示进度条停在高位
- 保留一个弱化的“返回星图”次按钮

交互规则：
- 点击“再折一次”后 1 秒内回到当前关卡
- 默认焦点始终放在主按钮上

## 7. ClearResult 通关页
页面目标：
- 给出轻快正反馈
- 鼓励继续下一关

建议内容：
- 主文案：“亮起来了”
- 补充文案：“这次折得刚刚好”
- 按钮 1：下一关
- 按钮 2：返回星图

## 8. Settings 设置页
页面内容：
- 音效开关
- 音乐开关
- 振动开关
- 隐私说明入口
- 版本号

交互规则：
- 从 Home 和 Gameplay 都可以进入
- 关闭后返回上一个页面

## 9. 页面间跳转规则
- Home -> LevelMap：点击开始折光
- Home -> Settings：点击设置
- LevelMap -> Gameplay：点击关卡节点
- Gameplay -> FailResult：达成失败条件
- Gameplay -> ClearResult：光线抵达终点
- FailResult -> Gameplay：点击“再折一次”
- ClearResult -> Gameplay：点击下一关
- ClearResult -> LevelMap：点击返回星图

## 10. 流程设计原则
- 任何一次失败都应在 2 步内回到可操作状态。
- 任何结果页都不应堆太多功能按钮。
- 首页、星图、结果页都要留出足够空白，维持清亮呼吸感。
